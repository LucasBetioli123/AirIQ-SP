# Versioned sample

Generated by `python -m src.aq.build_dataset --make-sample` from the full data.

| File | Contents |
|---|---|
| `station_days.parquet` | ESTIMATE table: 1 row per station x day (Jan 2021-Apr 2023), measured PM2.5 + every feature |
| `station_days_fc.parquet` | D+1 FORECAST table (observations up to D + known calendar of D+1, target PM2.5 of D+1) |
| `stations.parquet`, `pm25_daily.parquet` | CETESB stations (via OpenAQ) and daily means |
| `aod_daily.nc`, `no2_daily.nc`, `era5_daily.nc`, `fires_daily.parquet` | daily cubes (São Paulo grid) **only for the windows** in `configs/config.yaml > sample.context_windows` |
| `static_0p01.nc` | land use (WorldCover) and terrain (Copernicus DEM), 0.01° grid |
| `municipios_sp.csv`, `sp_boundary.wkt` | municipal seats and state outline (IBGE) |
| `rag_chunks.jsonl` | regulation base already split into passages (so the agent runs without downloading the regulations; Portuguese text) |

With the sample, `make all-sample` reproduces the benchmark, intervals, D+1, SHAP and episodes
(the same numbers as docs/TECHNICAL_DETAILS.md) in minutes. Maps, CLI and API work on the
dates inside the windows. For the full period: `make data`.

Schema `causal-spatial-aod-v2`: spatial-only AOD gap-filling (cell, 3x3, 9x9, or NaN); it
never uses tomorrow's observed AOD or weather. The migration of legacy tables is reproduced by
`python -m scripts.migrate_causal_sample`. `make all-sample` is also available as
`python -m src.aq.pipeline`, without GNU Make.
